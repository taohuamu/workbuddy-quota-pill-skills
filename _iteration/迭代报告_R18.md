## 1. 变更依据（不是拍脑袋选字段）

先确认平台读哪个字段。查本机三个从市场装过的技能的 `_skillhub_meta.json`：

```json
{
  "name": "积分打卡管家",          ← 市场展示名称
  "description_zh": "授权一次，之后每天自动完成…",   ← 能力介绍
  "description_en": "Authorize once and the whole daily routine…",
  "skillId": "skill_2115975633016471552", "version": "1.0.0"
}
```

结论：**市场展示名称 ← `display_name`，能力介绍 ← `description_zh` / `description_en`**，
而 `description` 是给模型做路由用的。所以本轮只改前者，`description` 保持原样——
它的 190 字里带着「额度、配额、限额还剩多少」「为什么数字不动」「快用完时提醒我」这些
触发词，改了就得重跑真路由验证（0.5.4 那次 5/5 + 0/4 的结论作废）。
